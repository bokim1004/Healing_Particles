# 🌀 Healing Particles

감정을 입력하면 파티클로 시각화하고, 호흡 가이드와 함께 치유 경험을 제공하는 인터랙티브 미디어 아트 웹 애플리케이션입니다.

---

## ✨ 주요 기능

### 감정 인식 & 시각화
- 사용자가 입력한 감정 텍스트(한국어/영어)를 분석하여 **5가지 감정 카테고리**로 분류합니다:
  - 🔴 **분노** — 빨간 계열 → 따뜻한 주황으로 치유
  - 🔵 **슬픔** — 파란 계열 → 황금빛으로 치유  
  - 🟣 **불안** — 보라 계열 → 부드러운 베이지로 치유
  - ⚪ **피로** — 회색 계열 → 밝은 황금으로 치유
  - 🟡 **평화** (긍정적 감정) — 황금 계열 → 더 밝게 증폭

### 6단계 힐링 페이즈
| 페이즈 | 설명 |
|--------|------|
| **Input** | 감정 입력 화면 |
| **Scattered** | 파티클이 흩어진 상태로 표시, 터치 유도 |
| **Gathering** | 터치하면 파티클이 구 형태로 모임 |
| **Breathing** | 3회 호흡 가이드 (들이마시기 → 멈추기 → 내쉬기) |
| **Release / Amplify** | 부정적 감정은 흩어지며 사라짐 / 긍정적 감정은 빛나며 증폭 |
| **Peace** | 최종 평화 상태, 다시 시작 가능 |

### 파티클 시스템
- **2,200개**의 Three.js 파티클을 커스텀 GLSL 셰이더로 렌더링
- **황금비 나선** 기반의 구 형태 모임 애니메이션
- **Additive Blending**으로 빛나는 글로우 효과
- 각 파티클의 꼬리 트레일(잔상) 라인 효과
- 부드러운 색상 전이 (감정색 → 치유색)

## 📁 프로젝트 구조

```
src/
├── main.jsx                    # 앱 엔트리 포인트
├── App.jsx                     # 루트 컴포넌트
├── index.css                   # 글로벌 스타일 (body 리셋)
├── HealingParticles.jsx        # 메인 컴포넌트 (훅 + 뷰 조합)
│
├── hooks/                      # 커스텀 훅 (로직)
│   ├── useHealingPhase.js      #   페이즈 상태 & 전환 관리
│   ├── useParticleScene.js     #   Three.js 씬 & 파티클 렌더링
│   └── useBreathingGuide.js    #   호흡 가이드 사이클 & 자동 전환
│
├── components/                 # UI 컴포넌트 (뷰)
│   └── PhaseOverlay.jsx        #   페이즈별 오버레이 UI
│
└── utils/                      # 유틸리티 (순수 함수)
    ├── emotionPalette.js       #   감정 분석 & 색상 팔레트
    └── koreanHelper.js         #   한국어 조사 처리 (이/가)
```

### 관심사 분리

- **로직 (hooks/)**: 상태 관리, Three.js 렌더링, 호흡 타이머 등 모든 비즈니스 로직
- **뷰 (components/)**: props만 받아 렌더링하는 순수 프레젠테이션 컴포넌트
- **유틸리티 (utils/)**: 상태 없는 순수 함수 (감정 분석, 한국어 처리)

## 🎨 사용자 흐름

```
감정 입력 → 파티클 시각화 → 터치 → 파티클 모임
    → 호흡 가이드 (3회) → 감정 해소/증폭 → 평화
                                              ↓
                                         [다시 시작]
```

1. 화면에 현재 느끼는 감정을 입력합니다 (예: "화가나", "슬퍼", "불안해")
2. 감정에 맞는 색상의 파티클이 흩어진 상태로 나타납니다
3. 화면을 터치하면 파티클이 구 형태로 모입니다
4. 호흡 가이드를 따라 3회 심호흡을 합니다
5. 부정적 감정: 파티클이 서서히 퍼지며 사라집니다  
   긍정적 감정: 파티클이 더 밝게 빛나며 증폭됩니다
6. 최종 평화 메시지와 함께 "다시 시작" 버튼이 나타납니다
